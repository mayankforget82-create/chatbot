# Python Programming Lab

This repository contains Python programs and laboratory exercises developed for learning and practicing Python programming.

## 📂 Contents

* **Python Lab Programs** – `python lab.py` to `python lab9.py`
* **Practice Programs** – Various Python practice files
* **AI Chatbot** – `ai chatbot.py`
* **Other Programs** – Additional Python exercises and experiments

## 🛠️ Requirements

* Python 3.x
* Any Python IDE such as VS Code, PyCharm, or IDLE

## ▶️ How to Run

Run any program using:

```bash
python filename.py
```

Example:

```bash
python "ai chatbot.py"
```

## 🎯 Purpose

The project is created for **Python learning, laboratory practice, and basic AI chatbot development**.
